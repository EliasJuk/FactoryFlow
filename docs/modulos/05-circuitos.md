```powershell
# Tela principal: 
- Circuitos
  - Lista de circuitos
  - Busca
  - Paginação
  - Editar
  - Inativar
  - Ver inativos
  - Restaurar
  - Excluir permanente
  - Botão Montar Circuito

# Ao clicar em “Montar Circuito”
- Abre um modal com os componentes daquele circuito:
  - Lista de componentes vinculados
  - Quantidade
  - Remover componente
  - Botão Adicionar componente

# Ao clicar em “Adicionar componente”
- Abre outro modal pequeno:
  - Selecionar componente
  - Informar quantidade
  - Adicionar
```
